📖 Tentang

Repositori ini dirancang khusus untuk Guru Informatika yang ingin menguasai Python dari dasar hingga mahir. Setiap modul dibangun di atas modul sebelumnya — urut, terstruktur, dan siap pakai untuk mengajar.


Ditulis dengan pendekatan learning by doing — banyak contoh kode, latihan, dan projek nyata yang relevan dengan dunia pendidikan.


Natedekaka — Ayah tiga anak, Guru Informatika, Spesialis Administrasi Server, Pengembang Web, & Linux Enthusiast.

📋 Cara Belajar

  1. Pelajari modul urut dari 0 → 13
  2. Tulis kode, jangan copy-paste
  3. Kerjakan semua latihan sebelum lanjut
  4. Baca error — "error itu guru terbaik"
  5. Eksperimen bebas di REPL (python di terminal)

🗺️ Alur Belajar

Ikuti langkah-langkah ini secara berurutan

TAHAP 1

🔰 Fondasi — Modul 0 → 2

Setup lingkungan, variabel, tipe data, string. Siapkan REPL dan tulis program pertama.

TAHAP 2

📊 Struktur Data — Modul 3 → 4

List, tuple, dictionary, set. Kuasai cara menyimpan dan mengelola kumpulan data.

TAHAP 3

⚙️ Kontrol Alur — Modul 5 → 7

Percabangan, perulangan, function. Logika pemrograman dan reusable code.

TAHAP 4

🛠️ Lanjutan — Modul 8 → 11

Error handling, file I/O, module/pip, list comprehension. Program yang robust.

TAHAP 5

🎯 Mahir — Modul 12 → 13

OOP dan proyek akhir. Bangun aplikasi CLI nyata untuk portofolio mengajar.
